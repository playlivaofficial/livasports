# Server-side creative fonts

Unmodified Liberation Sans 2.1.5 (Regular, Bold, Italic, BoldItalic).
SIL Open Font License 1.1; full upstream copyright/license accompanies the fonts in LICENSE.

Source: https://github.com/liberationfonts/liberation-fonts/releases/tag/2.1.5
Archive: https://github.com/liberationfonts/liberation-fonts/files/7261482/liberation-fonts-ttf-2.1.5.tar.gz
Archive SHA-256: 7191c669bf38899f73a2094ed00f7b800553364f90e2637010a69c0e268f25d0

Bundled for commercial creative output on fontless Linux/serverless instances. Fontconfig aliases
the existing Arial/Helvetica/sans-serif requests to this metric-compatible font; it does not change
the approved layouts, copy, colours or character art. No Windows proprietary font is redistributed.
The renderer checks actual glyph rendering before generating a video, failing closed on tofu text.
