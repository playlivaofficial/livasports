## What is already deployable (no owner action)

* Primary sitemap: `https://livasports.com/sitemap.xml`

## Google Search Console — exact owner steps

1. Open https://search.google.com/search-console and add a **Domain** property for `livasports.com` (covers http/https and all locale paths). Verification is via a DNS TXT record on the apex domain (the record name/value is generated by Search Console; add it in the DNS provider that serves `livasports.com`). This is an owner-only DNS change — not performed by P2.
   * Alternative without DNS: a **URL-prefix** property `https://livasports.com/` verified with the HTML-tag method. If the owner chooses this, add the provided `google-site-verification` value to `src/app/layout.tsx` under `metadata.verification.google` (Next.js native field) and redeploy — one line, no other change.
2. After verification, submit both sitemaps in *Indexing → Sitemaps*: `https://livasports.com/sitemap.xml` and `https://livasports.com/sports-sitemaps.xml`.
3. Inspect these representative canonical URLs with *URL Inspection* and record the result in `docs/P2_RELEASE_EVIDENCE.md`:
   * `https://livasports.com/br/futebol?competition=brasileirao-serie-a`
   * `https://livasports.com/br/futebol?competition=brasileirao-serie-a&tab=standings`
   * `https://livasports.com/mx/futbol?competition=liga-mx`
   * `https://livasports.com/en/football?competition=premier-league&tab=results`
   * one `/br/jogo/...`, one `/br/time/...`, one `/mx/jugador/...` from the entity sitemaps
   * `https://livasports.com/br/como-funciona-a-comparacao-de-odds`
4. Do **not** use the Indexing API for sports pages (it is limited to JobPosting/BroadcastEvent) and do not add sitemap-ping automation (retired by Google).

## Bing Webmaster Tools — exact owner steps

1. https://www.bing.com/webmasters → *Add a site* → `https://livasports.com`. If a Search Console property exists, use *Import from Google Search Console* (no new token needed). Otherwise verify with the same DNS CNAME/TXT or the `msvalidate.01` meta tag (`metadata.verification.other['msvalidate.01']` in `src/app/layout.tsx`).
2. Submit `https://livasports.com/sitemap.xml` and `https://livasports.com/sports-sitemaps.xml` under *Sitemaps*.
3. IndexNow is optional and not part of P2; it would require a key file at the site root and a deliberate decision.

## After verification — what to monitor (no new analytics milestone)

Weekly, from Search Console *Performance* and *Pages*: impressions and clicks by country (BR, MX, other), CTR by landing-page group (competition hubs, matches, teams, players, help), number of indexed canonical pages versus "Duplicate, Google chose different canonical", "Crawled – currently not indexed", and hreflang errors under *International targeting*. Existing product analytics (`/api/events`) stay as-is.
